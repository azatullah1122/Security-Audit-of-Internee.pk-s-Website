Internee.pk Web Vulnerability Assessment

Project Overview

This project focuses on identifying and documenting common web application security vulnerabilities in a controlled and authorized environment.

Testing is intended for the Internee.pk staging website with permission and the deliberately vulnerable OWASP Juice Shop application.

Objectives

Assess critical web application areas such as login pages, user profiles, and APIs.

Identify common vulnerabilities including SQL Injection, Cross-Site Scripting (XSS), and Cross-Site Request Forgery (CSRF).

Use OWASP ZAP and Burp Suite for security testing and analysis.

Document security findings and provide remediation recommendations.

Improve data protection and overall web application security.
